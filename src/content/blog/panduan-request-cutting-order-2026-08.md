Memesan jasa laser cutting untuk pertama kali bisa terasa membingungkan. Mau kirim file apa? Format apa? Informasi apa yang perlu disertakan? Dan bagaimana proses selanjutnya sampai produk tiba di tangan kamu?

Panduan ini menjawab semua pertanyaan itu secara sistematis — dari langkah pertama mempersiapkan file hingga produk jadi siap diterima. Tepat Laser menyusun panduan ini berdasarkan pengalaman menangani ribuan order dari berbagai industri.

## Langkah 1: Persiapkan File Desain yang Benar

Kualitas hasil cutting sangat bergantung pada kualitas file desain yang dikirimkan. Ini adalah langkah paling kritis dalam seluruh proses.

### Format File yang Diterima

Tepat Laser menerima format file berikut:

- **DXF** — format universal yang kompatibel dengan semua software CAD dan CNC
- **DWG** — format AutoCAD, ideal untuk desain teknikal
- **AI (Adobe Illustrator)** — untuk desain berbasis vektor
- **CDR (CorelDRAW)** — populer di industri kreatif lokal
- **SVG** — untuk desain sederhana berbasis web

Jangan kirim JPG, PNG, atau PDF tanpa layer vektor — file bitmap tidak bisa langsung diproses mesin laser dan membutuhkan konversi ulang yang memakan waktu dan berpotensi kehilangan akurasi dimensi.

### Standar File yang Baik

- Semua garis potong menggunakan **warna merah (RGB: 255,0,0)**
- Warna hitam atau biru untuk area yang akan di-engrave
- Tidak ada garis ganda (duplicate lines) — menyebabkan mesin cutting dua kali di jalur yang sama
- Semua path tertutup sempurna untuk area yang akan dipotong tembus
- Ukuran file sesuai ukuran produk nyata (skala 1:1)

## Langkah 2: Tentukan Spesifikasi Material

Setelah file siap, informasi berikut harus disertakan dalam permintaan order:

- **Jenis material**: besi (mild steel), stainless steel grade 304/316, aluminium, atau lainnya
- **Ketebalan material**: dalam satuan milimeter — contoh: 2mm, 5mm, 10mm
- **Apakah material disediakan sendiri atau minta dari vendor?** Tepat Laser bisa menyediakan material sesuai spesifikasi
- **Kondisi permukaan**: apakah boleh ada bekas mill scale, atau perlu permukaan bersih?

## Langkah 3: Tentukan Jumlah dan Spesifikasi Produksi

Informasi produksi yang jelas membantu tim kalkulasi memberikan harga yang akurat dan tidak berubah di tengah jalan.

- **Jumlah unit** yang dibutuhkan
- **Toleransi khusus** jika ada — contoh: toleransi ±0,1mm untuk komponen presisi tinggi
- **Finishing yang dibutuhkan**: deburring, sandblasting, coating, atau tanpa finishing
- **Deadline produksi** yang dibutuhkan

## Langkah 4: Proses Kalkulasi dan Penawaran Harga

Setelah semua informasi diterima, tim Tepat Laser memproses kalkulasi yang mencakup:

- Estimasi waktu cutting berdasarkan total panjang jalur potong
- Kebutuhan material termasuk waste factor
- Biaya setup dan programming jika diperlukan
- Biaya finishing tambahan
- Biaya pengiriman jika dikirim

Harga biasanya dikirimkan dalam **1×24 jam kerja** untuk order standar. Order dengan spesifikasi kompleks atau volume besar mungkin memerlukan diskusi teknikal lebih lanjut.

## Langkah 5: Konfirmasi Order dan Down Payment

Setelah penawaran disetujui, lakukan konfirmasi order dengan:

1. Menyetujui spesifikasi dan harga secara tertulis (via WhatsApp atau email)
2. Membayar Down Payment sesuai ketentuan — biasanya 50% dari total harga
3. Mengirimkan file desain final yang sudah disetujui

Order masuk ke antrian produksi setelah konfirmasi dan DP diterima.

## Langkah 6: Produksi dan Quality Control

Di tahap ini, mesin fiber laser Tepat Laser mulai bekerja. Beberapa hal yang perlu diketahui:

- Estimasi waktu produksi diberikan saat konfirmasi order
- Untuk order pertama atau spesifikasi baru, dilakukan **trial cut** pada material kecil sebelum produksi penuh
- Foto hasil produksi dikirimkan untuk persetujuan sebelum pengiriman
- QC meliputi pengecekan dimensi, kerapian tepi, dan kesesuaian dengan file desain

## Langkah 7: Pengiriman atau Pickup

Setelah produk melewati QC, pilih metode pengambilan:

- **Pickup langsung** ke workshop Tepat Laser — pelunasan dilakukan saat pickup
- **Pengiriman** via ekspedisi — produk dikemas dengan aman, biaya kirim ditanggung pembeli

## Tips agar Order Berjalan Lancar

**Kirim file dan spesifikasi lengkap dari awal.** Semakin lengkap informasi, semakin cepat dan akurat penawaran harga. Informasi tidak lengkap menyebabkan bolak-balik klarifikasi yang memakan waktu.

**Diskusikan toleransi secara eksplisit.** Jangan asumsikan vendor tahu toleransi yang dibutuhkan. Sebutkan angkanya secara spesifik — ±0,1mm sangat berbeda dengan ±1mm dalam konteks produksi.

**Minta sampel untuk order pertama produk baru.** Sebelum produksi massal, order sampel 1–3 unit untuk memverifikasi kesesuaian ukuran dan kualitas sebelum berkomitmen pada volume besar.

**Berikan waktu buffer yang cukup.** Hindari memesan dengan deadline sangat mepet. Order rush memiliki risiko lebih tinggi dan biasanya dikenakan biaya tambahan.
